# CyberLog Analyzer

Estrutura inicial para um projeto de análise de logs de segurança cibernética.

## Estrutura

- `src/`: código-fonte da aplicação.
- `reports/`: relatórios gerados pela análise.
- `logs/`: arquivos de log usados como entrada.

## Próximos passos

1. Adicionar o analisador em `src/`.
2. Colocar os logs de entrada em `logs/`.
3. Salvar os resultados em `reports/`.
